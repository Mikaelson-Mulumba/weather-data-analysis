🌦️ Weather Data Analysis Project
              Overview
An exploratory data analysis (EDA) on a real-world weather dataset containing 8,784 rows and 8 columns of hourly weather recordings.
-Dataset Columns
-Date/Time
-Temp_C
-Dew Point Temp_C
-Rel Hum_%
-Wind Speed_km/h
-Visibility_km
-Press_kPa
-Weather Condition

         What Was Analyzed
Dataset shape, structure, and data types
Null values check
Unique wind speed values
Frequency of each weather condition
Filtering by specific conditions
Mean, min, max per weather condition
Standard deviation of pressure
Variance of relative humidity
Complex multi-condition filtering

         Key Findings
✅ Zero null values in the dataset
🌤️ Most frequent condition: Mainly Clear (2,106 times)
👁️ Mean visibility: 27.66 km
📊 Std deviation of pressure: 0.844 kPa
💧 Variance of relative humidity: 286.25
